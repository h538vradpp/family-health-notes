# 【科普知识】采血注意事项

> 更新时间：2026-09-17 (UTC+8)

在生活中，无论是生病了需要检查还是健康体检，都会涉及到采血检查。

那么在采血前后都有哪些注意事项呢？

●**采血前的注意事项**●
1、采血前一天不宜吃过于油腻、高蛋白食物，否则会影响检测结果。有些脂代谢异常的人，抽出的血标本离心后上层血清及血浆都是乳白色，这类人群建议素食一周后再进行采血检查。

2、早晨抽血前空腹8～12小时。餐饮后，因将会影响血糖血脂等检测结果。空腹时间也不宜过长，处于饥饿时间过长，可使血糖、蛋白质降低，胆红素升高。

3、采血时间应避开服药期间，建议在服药前采血，具体的可提前咨询临床大夫。

4、采血前应避免剧烈运动，如果到医院采血时比较匆忙，建议至少休息15分钟后再采血。

5、采血当天，建议穿宽松的上衣，避免采血时衣袖卷不上去或采血后因衣袖过紧引起手臂血肿。

6、采血时应放松心情，避免因恐惧造成血管收缩，增加采血难度。

7、最好按规定时间采血。因为糖耐量检测等检查对时间要求非常严格。

●**采血后的注意事项**●
1、采血后需在针孔及向上两厘米进针处的范围进行局部按压3～5分钟，进行止血。千万不要揉，以免造成皮下血肿。

2、采血后按压时间应充分。按压时间应当长些，才能完全止血。如有出血倾向，应延长按压时间。

3、采血后要适当休息片刻，如果出现头晕、眼花、乏力等晕针情况，应立即平卧、饮少量糖水，待症状缓解后再进行下一步检查。

4、若局部出现淤血，24小时后可以用温热毛巾湿敷，促进吸收。
