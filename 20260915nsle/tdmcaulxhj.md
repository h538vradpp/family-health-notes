# 卵巢过度刺激综合征对做试管婴儿成功率的影响

> 更新时间：2026-09-15 (UTC+8)

卵巢过度刺激综合征(OHSS)对试管婴儿成功率的影响主要体现在以下几个方面：

　　1. **影响胚胎移植计划**

　　OHSS患者可能出现腹胀、腹水、胸水等严重症状，此时移植胚胎会加重OHSS的病情，甚至危及生命健康，因此通常需要取消本周期的胚胎移植。例如，唐思因OHSS导致腹水，最终取消了移植计划。

　　有研究显示，中重度OHSS患者的胚胎移植成功率并未显著低于无OHSS的患者，但OHSS的发生仍会导致移植周期的延迟。

　　2. **降低胚胎质量和数量**

　　OHSS往往与促排卵过程中卵泡发育过多有关，这可能导致卵子质量下降。虽然获卵数增加，但受精后能发育成可移植胚胎的比例可能降低。例如，唐思取出的4个卵子在体外受精后，未能发育成达到移植标准的囊胚。

　　OHSS的发生率与取卵数密切相关，取卵超过20颗时，OHSS风险超过10%，而轻度症状的发生率高达30%。

　　3. **影响子宫内膜容受性**

　　OHSS可能导致子宫内膜功能异常，影响胚胎着床。例如，OHSS患者可能出现子宫内膜血流异常，降低内膜容受性。

　　4. **增加治疗风险和心理负担**

　　OHSS不仅影响身体状态，还可能增加患者的焦虑和心理压力。患者可能需要多次尝试试管婴儿，每次失败都会带来巨大的心理负担。

　　5. **对后续治疗的影响**

　　对于发生OHSS的患者，医生可能会调整促排卵方案，如采用“长方案”或“拮抗剂方案”，以降低OHSS风险。这些调整可能会影响后续周期的成功率，但有助于减少并发症的发生。

　　OHSS对试管婴儿成功率的影响是多方面的，主要通过影响胚胎移植计划、降低胚胎质量和数量、影响子宫内膜容受性等方式体现。虽然有研究显示OHSS患者的妊娠率并未显著低于无OHSS的患者，但OHSS的发生仍会增加治疗的复杂性和风险，因此预防OHSS的发生对提高试管婴儿成功率至关重要。
