# 胎儿心率 210 次/分钟？这家医院 3 元药方来解决！

> 更新时间：2026-09-17 (UTC+8)

最近，温州市人民医院（温州市妇幼保健院）收到产科超声危急值警报：一位孕妇腹中胎儿心率过快，达到 180 次 / 分钟！超声医生立刻打电话告知情况，怀疑胎儿存在心律失常。医院迅速启动门诊应急预案，将孕妇带到胎心监护室。在排除胎儿宫内窘迫后，检查发现，胎儿心率持续在 210 次 / 分钟以上，胎动如常，首先考虑快速型心律失常。

孕妇和家属心急如焚，胎儿心跳不规律，是不是意味着有大问题？需不需要治疗？宝宝的心跳最后恢复正常了吗？别着急，答案在文末，咱们先来一起科学认识胎儿心律失常，消除大家的误解，守护宝宝最初的 “心跳声”。

**什么是胎儿心律失常？**

胎儿心律失常，简单来说，就是胎儿心脏跳动的频率或节奏出现异常，可表现为心跳过快（心动过速）、过慢（心动过缓）或不规则（早搏等）。正常情况下，孕中期之后，胎儿心率稳定在 110 - 160 次 / 分钟。要是持续超出这个范围，或者心跳节奏乱了，就得引起重视。

据统计，胎儿心律失常的发生率在 1% - 3%。大部分只是暂时的、生理性的异常，不过，也有大约 10% 和心脏结构异常、潜在疾病有关。

**常见类型和原因有哪些？**

**房性早搏（PAC）：**这是最常见的类型，约占 80%。表现为心脏早搏后有代偿性停顿，主要是胎儿心脏传导系统还没发育成熟。多数情况下，到了孕晚期或者出生后就会自然消失，不用特别治疗。

**室上性心动过速（SVT）：**胎儿心率持续超过 200 次 / 分钟，可能是心脏传导通路异常或母体自身免疫疾病有关，比如抗 SSA/Ro 抗体呈阳性。要是不及时处理，可能会导致胎儿心力衰竭或者水肿。

**完全性房室传导阻滞（CAVB）：**胎儿心率低于 80 次 / 分钟，常和母体自身免疫性疾病，像系统性红斑狼疮有关，还可能伴有心脏结构异常。这种情况要密切监测，有些胎儿出生后需要安装起搏器。

**怎么诊断呢？**

**胎心监护和超声心动图：**常规产检的胎心监护能初步发现问题，但要确诊，还得靠胎儿超声心动图。这项检查可以清楚看到心脏结构、血流情况和心跳节律，判断胎儿有没有先天性心脏病。

**母体血液检查：**要是怀疑是免疫方面的原因，比如完全性房室传导阻滞（CAVB），就要检测母体的抗核抗体、抗 SSA/Ro 抗体等。

**要不要干预？**

**生理性早搏：**一般不用治疗，增加产检次数，观察变化就行。

**快速性心律失常（如 SVT）：**可以让母体口服地高辛、氟卡尼等药物，药物通过胎盘作用于胎儿，控制心率。

**严重心动过缓或传导阻滞：**要是胎儿出现心力衰竭的迹象，可能就得提前分娩，出生后安装起搏器。

**合并心脏结构异常：**需要产科、儿科心脏科、新生儿科等多学科团队一起合作，制定分娩计划和出生后的手术方案。

**给准父母的建议**

**保持冷静，及时就医：**大多数胎儿心律失常都是良性的，过度焦虑反而不利于孕期健康。发现问题后，尽快去有胎儿医学中心的医院做进一步评估。

**重视孕期健康管理：**孕期要避免吸烟、喝酒，预防感染（比如风疹病毒），有自身免疫性疾病的准妈妈要控制好病情，降低胎儿心脏出现异常的风险。

**理性看待预后：**现在胎儿心脏介入技术越来越先进，就算是复杂的心律失常，出生后通过药物、手术或者安装起搏器等治疗，孩子也能有不错的生活质量。 

回到开头提到的那位孕妇，她口服地高辛，每天三次，每次 25mg，第二天中午胎儿心律就恢复正常了！ 

胎儿心律失常可能只是发育中的小波折，也可能是健康预警。准父母们要相信现代医学的实力，积极配合医生，守护好宝宝的小心脏。每一次不规律的心跳，都是小生命努力适应世界的证明。
